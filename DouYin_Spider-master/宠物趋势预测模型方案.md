# 宠物服饰趋势预测量化模型 · 数据可得性核查与修正方案

> 品牌：Z.paw（高端宠物服装，客单价 1500 元，高定宠物穿搭）
> 本文档在初版方案基础上，**逐因子核验真实数据可得性**，剔除"拿不到数"的伪因子，只保留有真实数据支撑的设计。
> 数据可得性分级：✅ 现有代码可直接采集 / ⚠️ 需新增采集或代理指标 / 🔧 AI 估计或静态知识库 / ❌ 当前拿不到（已剔除）

---

## 0. 核心结论（先看这里）

1. 你的判断是对的：初版方案里 **「关键词搜索量」「加购量」「小红书/B站/ins 笔记量」等因子拿不到真实数据**，属于纸面设计。
2. **真正能稳定采集到硬数据的只有两个平台**：
   - 抖音：作品发布量、互动量、发布时间、作者粉丝数、话题标签、评论内容
   - 淘宝：商品名、价格、店铺、链接、付款人数（销量）
3. 修正后：模型改为**「抖音 + 淘宝硬数据」打底 + 「AI 估计/静态知识库」辅助 + 「小红书/B站/1688」作为后续增强**，先上线可采集部分，拿不到的坚决不进因子公式。

## 4. 双阶段模型（不变）

### 4.1 阶段一：复合加权（冷启动，可上线）
```
TrendScore = 0.30*增长动能 + 0.30*受众质量 + 0.20*风格迁移
           + 0.15*可行性 − 0.05*噪声衰减
```
| 分数 | 判定 | 动作 |
|------|------|------|
| > 0.75 | 高潜力早期 | 优先立项 |
| 0.55~0.75 | 观察 | 小成本素材测试 |
| 0.35~0.55 | 成熟期 | 谨慎入场 |
| < 0.35 | 衰退/伪趋势 | 放弃 |

### 4.2 阶段二：XGBoost 时序（样本 ≥120 后启用）
- 特征：上述因子时序 + 滞后特征；标签：未来 30/60 天真实涨幅
- 输出生命周期（萌芽/上升/顶峰/衰退）；禁大参数量深度模型
