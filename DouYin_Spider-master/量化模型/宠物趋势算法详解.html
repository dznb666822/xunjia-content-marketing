Z.paw · Trend Engine · 算法详解

宠物服饰趋势预测：从数据采集到分数的每一步

完整还原 23 个垂类词的算法链路：数据如何获取、子特征如何计算、如何归一化聚合、如何加权成 TrendScore、如何判定生命周期。所有公式与源码一一对应。

1总览：一条完整链路

数据采集（抖音/B站/淘宝/1688）→ 五因子 × 子特征（18 个）→ 子特征均值 = 分组得分→ 加权求和 = TrendScore→ 阈值判定 = 生命周期 + 动作
TrendScore = 0.30·增长动能 + 0.30·受众质量 + 0.20·风格迁移 + 0.15·可行性 − 0.05·噪声衰减

3归一化工具（计算技巧基础）

clamp01(x)
max(0, min(1, x))
把任意数值截断到 0~1，用于占比、比率、AI 分数等天然有界量的兜底。
growth_norm(g)
clamp01((g + 1) / 2)
把增速 g∈(−∞,+∞) 映射到 0~1：g=0 → 0.5（持平），g>0 → >0.5（增长），g<0 → <0.5（下滑）。
对数压平
log10(x + 1)
播放量/粉丝数跨度极大（几十到几百万），先取对数再归一，避免头部霸榜。

5聚合与加权

第一步：子特征 → 分组得分（组内算术平均）

group_score = mean(该因子下所有子特征)

增长动能/受众质量/可行性/噪声衰减取组内均值；风格迁移只有 1 个子特征，直接取值。这样每个因子得分都在 0~1。

第二步：分组得分 → TrendScore（加权求和，噪声为负）

TrendScore = clamp01( Σ weight × group_score )

噪声衰减是唯一负权重（−0.05），因为它衡量的是内卷/低价/网红梗风险，分数越高反而要扣分。
