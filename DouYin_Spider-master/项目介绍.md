## 一、项目概述

本项目是在开源项目 [DouYin_Spider](https://github.com/cv-cat/Douyin_Spider)（抖音数据采集/直播间监听/私信收发）基础上，二次开发的一套 **抖音内容运营一体化平台**。在保留原有爬虫能力之外，新增了品牌管理、竞品发现、AI 视频分析、脚本生成、投流分析、竞品价格调研、意向客户分析、热点雷达、智能混剪（含 TTS 配音）等 AI 增值能力，并提供 Web 控制台（前后端不分离，Flask + 原生 JS）。

一句话定位：**从「竞品数据采集 → AI 内容分析 → 脚本/混剪生产 → 数据看板」的抖音内容运营闭环。**

## 二、技术栈

| 层 | 技术 |
|----|------|
| 后端 | Python 3.11 + Flask + APScheduler |
| 前端 | 原生 HTML/CSS/JS（单页应用，`templates/index.html` + `static/js/*`） |
| AI 大模型 | 火山方舟 Ark API，模型 `doubao-seed-2-0-pro-260215`（多模态 + 文本） |
| TTS | 阿里开源 CosyVoice-300M-SFT（本地部署于 WSL2，HTTP 服务端口 50000） |
| 数据库 | MySQL（默认也支持 JSON 文件后端，通过 `STORAGE_BACKEND` 切换） |
| 音视频处理 | FFmpeg / FFprobe |
| 爬虫 | 抖音 Web 接口（X-Bogus / A-B / msToken 签名）、Selenium（淘宝价格调研） |
| 热点雷达 | 独立子系统 trendradar（RSS 采集 + SQLite + AI 分析 + 通知推送） |

## 四、已开发功能（按模块）

### 4.1 账号与权限管理
- 注册 / 登录 / 登出 / 当前用户信息（`/api/auth/*`）
- 管理员用户管理：用户列表、按用户分配可用功能（`/api/admin/users*`）
- 数据按用户隔离：`services/storage.py` 对 brands / competitors / videos / tasks / media_library / mashup_results 做了 owner 隔离

### 4.2 品牌与 SKU 管理
- 品牌 CRUD，含品类、目标人群、产品描述、风格调性、卖点
- 每个品牌下可维护多个 SKU（含各自文案/脚本）
- 端点：`/api/brands`、`/api/brands/<id>/skus` 等

### 4.3 竞品发现与管理
- 竞品博主 CRUD + 一键拉取视频（`/api/competitors*`）
- **同赛道发现**（三步评估）：
  1. 粉丝量级门槛（分段策略）
  2. 数据稳定向好（近 3 月更新 + 点赞趋势）
  3. 内容可复制性 AI 评分（分批调用豆包）
  - 结果全部展示并附理由，人工复核后「添加到监听」
- **跨赛道推荐**：AI 推荐可借鉴品类（`/api/discovery/*`）

### 4.4 监听中心（定时调度）
- APScheduler 定时任务：每日 10:00 扫描新博主、11:00 监听已关注博主新视频
- 支持手动触发、状态查询、博主列表管理、新博主/新视频查看
- 端点：`/api/monitor/*`

### 4.5 数据看板
- 视频互动数据统计、按品牌/博主/类型/时间筛选
- 采集最新互动数据
- 端点：`/api/dashboard/*`

### 4.6 视频内容分析（多模态）
- 上传视频到火山方舟 Files API，豆包多模态分析输出：文本结构（钩子/正文/CTA）、视频类型、场景、情绪
- 封面图描述、视频首帧提取
- 批量分析、下载后自动分析、历史记录、Excel 导出
- 端点：`/api/analysis/*`、`/api/videos/first-frame/*`、`/api/video/download-and-analyze`

### 4.7 投流分析
- 基于互动数据（播放/点赞/评论/分享/收藏）+ 内容结构，AI 输出投流建议、预算、受众、ROI、优化建议
- 单视频分析 + 多视频对比
- 端点：`/api/ad/*`

### 4.8 脚本生成
- 基于对标视频结构生成参考脚本（Hook/Body/CTA/完整脚本）
- 按视频类型生成脚本模板
- 从分析结果一键生成脚本、历史、Excel 导出
- 端点：`/api/scripts/*`

### 4.9 竞品价格调研（淘宝）
- 输入关键词，Selenium 爬取淘宝商品（名称/价格/店铺/链接/图片），落库 MySQL
- 历史记录、详情查看
- 端点：`/api/price-research/*`
- 关键文件：`services/price_research.py`、`services/taobao_api.py`

### 4.10 意向客户分析
- 输入抖音视频链接，抓取评论区，豆包 AI 逐条判定「高/中/低/无」购买意向，落库 MySQL
- 历史记录、详情查看
- 端点：`/api/intent/*`
- 关键文件：`services/intent_analyzer.py`

### 4.11 智能混剪（素材库 + 分类 + TTS 配音 + 混剪）
- **素材库**：上传视频、列表、删除（`/api/videos/*`）
- **视频分类**：AI 对素材做分类 + 时间线片段标注（`/api/videos/classify*`）
- **TTS 配音**：
  - CosyVoice 预置 7 个音色（中/英/日/韩 男女声）
  - 按「风格调性 + 文案」智能音色配对
  - 上传参考音频克隆音色
  - 端点：`/api/videos/tts/voices`、`/api/videos/tts/clone-audio`
- **混剪**：文案拆分 → AI 匹配视频片段 → 每段台词一倍速配音 → 画面按台词时长匹配（不足自动循环）→ 片尾短空隙 → FFmpeg 拼接
  - 单 SKU 混剪、品牌批量混剪、任务状态、下载、播放、结果列表
  - 端点：`/api/videos/mashup*`、`/api/mashup/results`
- 关键文件：`services/video_mashup.py`、`services/video_classifier.py`、`services/tts.py`

### 4.12 热点雷达（trendradar 子系统）
- RSS 采集 → AI 过滤/分析/翻译 → 报告生成（HTML）→ 通知推送（飞书等）
- 提供状态查询、手动运行、报告查看、配置读写
- 端点：`/api/trendradar/*`、`/trendradar/report/<path>`

### 4.13 抖音手动工具（原始爬虫能力）
- 搜索：视频/用户/直播（`/api/search_*`）
- 用户：信息/全部作品/粉丝/关注（`/api/get_user_*`、`/api/get_follower_list` 等）
- 作品：详情/评论/下载（`/api/get_work_*`、`/api/download_work`、`/api/works/download`）
- 直播：信息/发弹幕/点赞（`/api/get_live_info`、`/api/live/*`）
- 互动：点赞/收藏/评论（`/api/digg`、`/api/collect_aweme`、`/api/publish_comment`）
- 私信：创建会话/发消息（`/api/create_conversation`、`/api/send_msg`）
- 推荐流/通知/我的 ID（`/api/get_feed`、`/api/get_notice_list`、`/api/my_uid`）

### 4.14 AI 提示词管理
- 在线查看/编辑 `config/` 下的提示词文件（`/api/prompts`）

### 4.15 登录凭证管理
- 扫码登录、保存凭证、证书提取（`/api/save_auth`、`/setup`、`/extract_cert`）

## 五、数据存储架构

- 通过 `services/storage.py` 门面统一读写，对外提供 `save_all / load_all / save_one / update_one / delete_one / find_by_id / find_by` 等接口。
- 通过 `.env` 的 `STORAGE_BACKEND` 在 `json` / `mysql` 之间切换；**当前部署为 `mysql`**。
- MySQL 表：brands / competitors / videos / tasks / media_library / mashup_results / intent_analysis / price_research 等（建表在 `services/storage_mysql.py`）。
- 用户数据隔离：`SCOPED_ENTITIES` 内的实体按 `owner_id` 隔离；管理员不受限。

## 七、未开发 / 未完整 / 待办事项

### 7.1 已开发但未完整集成到 Web 前端（半成品）
1. **直播间实时弹幕监听**：`dy_live/server.py` 是独立 WebSocket 脚本，需手动修改 `live_id` 才能监听指定直播间；前端「直播间」面板仅提供搜索/发弹幕/点赞等主动操作，**没有实时弹幕流展示**。
2. **私信实时接收**：`dy_apis/douyin_recv_msg.py` 是独立命令行脚本；前端「私信管理」面板提供会话/发消息等主动操作，**实时接收未接入 Web 界面**。

### 7.2 待完善 / 技术债
1. **前端「语速」控件残留**：后端已固定为一倍速合成（不再调速），但前端仍有语速选项，传入后被忽略。
2. **历史 JSON 数据未迁移 MySQL**：`datas/app_data/*.json`（品牌/竞品/视频/任务）与 `data/intent_analysis/`、`data/price_research/` 是切换 MySQL 前的历史数据，当前不会被读取。
3. **意向分析 / 价格调研未按用户隔离**：这两个实体不在 `SCOPED_ENTITIES` 内，所有登录用户看到的是同一份全局数据。
4. **弃用模型未删除**：WSL 内 `CosyVoice2-0.5B` 模型目录（约 7.6GB）已弃用（切换到 300M-SFT），未清理。
5. **弃用依赖未清理**：`requirements.txt` 中 `edge-tts` 已不再使用（改本地 CosyVoice）。

### 7.3 尚未开发的能力（基于当前 API 清单的客观缺口）
1. **混剪结果无删除接口**：只有 `/api/mashup/results` 列表，没有删除单个混剪结果的 API。
2. **跨模块批量导出**：仅视频分析（`/api/analysis/export`）和脚本（`/api/scripts/export`）支持 Excel 导出，品牌/竞品/意向/价格等模块无导出。
3. **无移动端 / 小程序端**。

## 八、环境配置与启动

### 8.1 关键环境变量（`.env`）
```env
DY_COOKIES='...'          # 抖音 Cookie（采集认证）
DY_LIVE_COOKIES='...'     # 直播 Cookie
ARK_API_KEY='...'         # 火山方舟 API Key
AI_API_URL='https://ark.cn-beijing.volces.com/api/v3'
AI_MODEL='doubao-seed-2-0-pro-260215'
STORAGE_BACKEND='mysql'   # 当前部署
MYSQL_HOST/PORT/USER/PASSWORD/DB
COSYVOICE_URL='http://127.0.0.1:50000'  # 可选，默认值
```

### 8.2 启动
```powershell
# 1) 主 Web 服务（端口 5000）
python web_server.py

# 2) CosyVoice TTS 服务（WSL 内，端口 50000）
wsl -d Ubuntu-22.04 -u root -- bash -c \
  "cd /root/CosyVoice && /root/cosyvoice_env/bin/python custom_server.py \
   --model_dir /root/CosyVoice/pretrained_models/CosyVoice-300M-SFT --port 50000"

# 3) 访问
# http://127.0.0.1:5000
```

> 注意：CosyVoice 服务为独立进程，主 Web 服务会在混剪/配音时调用它；若未启动，配音功能不可用。
