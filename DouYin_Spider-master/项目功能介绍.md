# 抖音电商运营工具箱 - 项目功能介绍

本项目是一个集成化的抖音电商运营辅助系统，提供从数据采集、竞品分析、内容创作到视频混剪的全链路功能。

---

## 一、抖音数据采集

### 1.1 搜索采集
- 关键词搜索抖音作品（支持排序、发布时间、时长、搜索范围等筛选）
- 搜索用户账号
- 搜索直播间
- 搜索结果支持批量下载（视频/图片）并导出 Excel

### 1.2 用户抓取
- 根据用户链接获取用户详细信息
- 获取用户全部作品列表（最多50个）
- 获取粉丝列表 / 关注列表

### 1.3 作品详情
- 根据作品链接获取作品详细信息（标题、播放量、点赞、评论、分享等）
- 获取作品的全部评论
- 下载作品视频或图片

### 1.4 推荐流
- 获取抖音推荐流视频数据
- 支持下载推荐流中的视频作品

### 1.5 通知中心
- 获取抖音系统通知消息列表

---

## 二、竞品分析

### 2.1 品牌管理
- 创建品牌画像（名称、品类、目标受众、产品描述、风格调性、卖点等）
- 查看/编辑/删除品牌信息

### 2.2 竞品发现
- 基于品牌画像自动搜索竞品博主
- 跨赛道竞品发现（探索不同品类的潜在竞品）
- 按关键词手动搜索竞品

### 2.3 竞品价格调研
- 在淘宝/京东/1688等平台按关键词搜索商品价格
- 自动采集商品名称、价格、店铺、链接
- 支持多平台对比和多页翻页
- 调研结果导出 CSV
- 调研历史记录查询

### 2.4 竞品广告分析
- 对竞品视频进行广告策略分析
- 多视频对比分析

---

## 三、监听中心

### 3.1 博主监听
- 添加博主到监听列表（通过抖音链接）
- 批量管理监听状态（暂停/恢复）
- 查看被监听博主的最新视频

### 3.2 视频抓取与分析
- 自动拉取监听博主的最新视频
- 对单个视频进行 AI 深度内容分析
- 查看分析结果（文本结构、产品分析、营销策略、分镜详情）

### 3.3 每日自动调度
- 定时任务：每日10:00自动扫描，11:00执行监听
- 自动检测新增视频并通知

---

## 四、AI 内容分析

### 4.1 视频内容分析
使用豆包 Seed 2.0 多模态模型对视频进行深度分析：

- **文本结构**：钩子（前3秒抓睛点）、正文叙事逻辑、转化引导策略
- **视频类型**：纯产品展示 / 使用教程 / 对比测评 / 剧情植入 / 专家讲解 / 用户证言 / 开箱体验 / Vlog种草
- **画面场景**：拍摄环境、人物状态、画面切换节奏、色调风格
- **情绪基调**：紧迫 / 温馨 / 专业 / 搞笑 / 惊讶 / 信任 / 焦虑
- **产品分析**：品类、核心卖点、目标受众、痛点
- **营销策略**：信任建立方式、紧迫感营造手法、互动引导
- **分镜脚本**：5-15个核心分镜，含景别、运镜、画面内容、台词、时长、关键帧时间

### 4.2 批量分析
- 支持多个视频批量分析
- 分析历史记录查询

---

## 五、脚本生成

### 5.1 AI 脚本创作
- 基于视频分析结果自动生成带货脚本
- 支持自定义 prompt 和生成变体数量
- 多种脚本类型（按品类/风格）

### 5.2 脚本管理
- 脚本历史记录查看
- 多版本对比
- 导出脚本为 Excel 报告

## 六、数据看板

### 6.1 视频统计
- 汇总统计：总视频数、总播放量、总点赞数、平均互动数
- 支持按品牌/竞品/视频类型/天数筛选
- 视频数据表格（含批量选择）

### 6.2 可视化图表
- 趋势折线图（Chart.js 渲染）
- 品牌/作者对比柱状图
- 实时数据采集更新

## 七、意向客户分析

- 输入抖音视频链接，AI 自动分析评论区用户意向等级
- 意向分级：高意向 / 中意向 / 低意向 / 无意向
- 提取意向类型、原因、关键点
- 分析结果表格展示（用户、评论、意向等级、类型）
- 历史分析记录查询

---

## 八、直播间管理

- 获取直播间实时信息
- 发送弹幕互动
- 直播间点赞

---

## 九、私信管理

- 创建私信会话
- 发送私信消息
- 通过用户 ID 发起对话

## 十、视频混剪

### 10.1 视频素材管理
- 拖拽上传或点击上传多个视频（支持 mp4/mov/avi/mkv/webm/flv）
- 视频素材库列表展示（含分类状态标签）

### 10.2 AI 智能分类
使用豆包 Seed 2.0 多模态模型自动分析视频：

- **标签分类**：场景类型、风格、情绪基调、人物特征、主题分类、视觉关键词、视频摘要、节奏、时长类别
- **内容时间线**：将视频按内容变化拆分为连续片段，每个片段含精确时间戳、画面描述、关键词标签、场景类型、是否有语音

### 10.3 文案匹配混剪
- 输入带货文案/脚本
- AI 将每句文案语义匹配到最相关的视频片段
- FFmpeg 按精确时间戳截取并拼接为完整视频
- 输出 MP4 文件可直接下载

### 10.4 镜头-台词对照
- 混剪完成后自动生成镜头与台词的详细对照文件
- 前端展示每个镜头的视频预览 + 对应台词 + 来源 + 时间范围 + AI匹配理由
- 支持鼠标悬停播放视频片段

## 十一、热点雷达

- 多平台热点聚合（头条、百度、微博、抖音、知乎等）

## 十二、互动操作

- 点赞 / 取消点赞视频
- 收藏 / 取消收藏作品

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML + CSS + 原生 JavaScript + Chart.js |
| 后端 | Python 3.11 + Flask |
| AI 引擎 | 火山方舟 Ark SDK（豆包 Seed 2.0 多模态模型）|
| 视频处理 | FFmpeg（截取/拼接）|
| 数据接口 | 抖音内部 API |
| 数据存储 | JSON 文件 + SQLite |
| 定时调度 | Python threading + 自定义调度器 |

## 快速启动

```bash
cd DouYin_Spider-master
python web_server.py
```

浏览器打开 http://127.0.0.1:5000

**视频混剪功能**需要额外安装依赖：
```bash
pip install volcenginesdkarkruntime loguru flask flask-cors
```

以及安装 FFmpeg 到本地。
